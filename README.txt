## Project Requirements

This project is a **basic To-Do List app** designed to help users manage their daily tasks easily.

### Core Features

- **Add a New Task**  
  Users can type a task and add it to the task list.

- **Toggle Task Completion**  
  Users can mark a task as completed or change it back to active.

- **Filter Tasks**  
  Users can filter the task list by:
  - **All** – shows all tasks  
  - **Active** – shows only incomplete tasks  
  - **Completed** – shows only finished tasks  

- **Save Tasks Automatically**  
  All tasks are saved using **localStorage**, so they remain available even after refreshing or reopening the browser.
